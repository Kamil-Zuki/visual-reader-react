# Visual Reader — План развития (Roadmap)

## 🎯 Цель проекта
Интерактивная читалка для технических книг с фокусом на глубокое понимание, визуализацию архитектур и активное усвоение материала (на примере "Designing Data-Intensive Applications"). 

Вектор развития: Уход от веб-версии (GitHub Pages) в сторону нативных кроссплатформенных приложений для Windows и Android.

## 🏗 Архитектура и Инфраструктура
- **Хранение данных:** Внутренняя база данных проекта (IndexedDB для локального хранения заметок, хайлайтов, прогресса и настроек ИИ).
- **Сборка приложения:** Использование Rust-библиотек (Tauri) для сборки React/Vite проекта в нативные standalone-приложения для Windows и Android.
- **Репозиторий:** Проект будет переведен в приватный репозиторий на GitHub.

## 🚀 Запланированные фичи (Features)

### 1. Прогресс чтения (Reading Progress)
*Трекинг активности для поддержания мотивации и регулярности.*
- Подсчет прочитанных глав и разделов.
- Общий процент завершения книги.
- Текущий "стрик" (streak) — счетчик дней непрерывного чтения.
- Визуализация прогресса (прогресс-бары, статистика).

### 2. Заметки и Хайлайты (Notes & Highlights)
*Базовый функционал для глубокой проработки текста.*
- Выделение фрагментов текста различными цветами.
- Добавление пользовательских заметок к любым выделенным фрагментам.
- Единый раздел (дашборд) для просмотра всех заметок по книге.
- Экспорт всех заметок, хайлайтов и ИИ-объяснений в единый Markdown-файл.

### 3. Граф концепций (Knowledge Map)
*Визуализация структурных связей между концепциями книги.*
- Построение графа зависимостей (например, `Replication` → `Consistency` → `Transactions`).
- Интерактивная навигация: клик по узлу графа автоматически переносит пользователя к нужному разделу книги.
- Автоматическая генерация или маппинг концепций с помощью ИИ.

### 4. Закладки (Bookmarks)
*Удобная навигация и отложенное чтение.*
- Быстрое сохранение позиции в книге с пометкой «вернуться сюда».
- Сборник всех закладок для быстрого доступа.
